## v1.4.0: Channel Points Redemptions

**Channel points redemptions now show their full detail in chat and the alerts panel, plus a fix for the release notes dialog.**

This release shows the reward name and point cost for every channel points redemption. Previously they were only visible, without detail, when the redemption included a chat message. It also fixes a crash in the release notes dialog and restyles its scrollbar.

### What's new?

* **Channel points redemptions**: now shown in both the chat and the alerts panel, with the reward name and point cost
* **Re-login required for full detail**: to see it, log in with Twitch once more from Settings, using the account that owns the channel (Twitch only grants this information to that account, not even to moderators). Without re-logging in, the app keeps showing what it showed before

### Bug Fixes

* **Release notes dialog**: fixed a crash when opening it on startup after an update
* **Release notes dialog**: its scrollbar now matches the rest of the app's style, replacing the "▼ Scroll for more" text
